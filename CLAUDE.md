## Development workflow

This project uses the devflow plugin
(https://github.com/tohammer/ai-dev-plugin). Docs live in `docs/`:
architecture.md, specs/, decisions/, backlog.md, next-steps.md.
Start a session by reading `docs/next-steps.md`.

`master` is protected on GitHub: every change, documentation included,
goes on a branch and in through a pull request, merged with a merge
commit.
